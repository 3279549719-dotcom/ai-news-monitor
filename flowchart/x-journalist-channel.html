🐍twikit 主通道抓取抓取 1

宿主 Python venv → scripts/x-fetch-tweets.py（~40 行，读 .env 凭证）→ get_user_tweets() 返回结构化 JSON：正文 / 绝对发推时间 / 状态 ID。用维护中 fork twifork（上游 twikit 已坏）。

🛟

📦crawl4ai 兜底通道抓取 2

twikit 失败（会话过期 / 被封 / 依赖缺失）→ 回退 crawl4ai guest 抓账号页 → markdown 解析推文卡（状态链接 + 正文 + 雪花 ID 解码时间）。两者都失败 → 跳过该源，不降级 Direct。

🃏

💬推文卡解析抓取 3

每条推文 = 一张卡：标题 = 推文正文（≤280 字符）、主链 = 原推状态链接、时间 = 真实发推时刻。纯文字爆料（无文章链接）不再漏。

🧠

⚖️预过滤 + AI 评分甄别

推文专用收紧词根预过滤（manchester / mufc / 红魔 / 球员名…）→ DeepSeek 评分 ≥60 入库。别队消息（West Ham / Baleba…）score <60 照旧过滤，不误入库。

📊

🗃️入库与前端产出

状态 URL 天然唯一 → URL 去重生效（裸 t.co 短链问题消失）；多记者同事件走现有交叉验证。前端 T1 推文卡按真实发推时间排序，30 天窗口正常命中。
